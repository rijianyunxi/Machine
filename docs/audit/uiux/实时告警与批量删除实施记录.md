# 实时告警与批量删除

## 页面改动
- 首页实时告警区：明确区分加载、空记录、更新失败、有数据；显示最近 10 条、3 秒刷新及更新时间。空状态提供检查监控入口，不把没有告警解释为监控正常。
- 有数据时分层展示规则、状态、监控名称、置信度和完整时间，记录可进入告警页。
- 告警记录：单条勾选、当前页全选、部分选择状态、取消选择、已选计数、二次确认和请求中锁定。
- 查询、翻页、刷新后清空选择；删除最后一页后回退到有效页。加载失败禁止继续删除旧列表。
- Light/Dark 共用语义色；桌面及 390/320px 布局回归无横向页面溢出，表格保留区域内滚动。

## 删除语义
- `POST /api/alerts/batch-delete`，请求 `{"ids": [1, 2]}`，仅接受 1–500 个正整数 ID，去重；不存在的 ID 忽略，支持重试。
- 删除记录及其未共享的 JPG 快照，并删除 `.thumbs/w*/` 中对应缓存，快照库通过文件系统枚举同步反映删除结果。
- 仍被未选告警引用的快照保留，删除结果反馈保留数量。
- 拒绝快照根目录外路径、越界符号链接；不存在的快照不阻止清理告警。
- SQL 事务内先将文件暂存到快照根目录的同级隔离目录，普通文件操作或 SQL 失败恢复文件并回滚记录；提交后清理隔离文件。
- SQLite 与文件系统不是跨资源原子事务：进程异常退出仍可能留下隔离目录。提交后隔离文件清理失败会返回 `cleanup_pending`，前端明确提示管理员检查日志，不能宣称磁盘空间已经全部回收。
- 使用既有服务认证；没有新增公开删除入口。未对用户现有告警执行删除测试。
