# 首页违规快照与趋势布局优化

## 布局
- 桌面：左侧实时告警，右侧纵向排列「最新违规快照」「近 7 天告警趋势」，左右底部对齐。
- 快照按一行三列展示，最多三张，不足三张不重复补图；图左下角深色渐变遮罩显示违规类型，未复核告警显示「待复核」。
- 点击图片使用现有灯箱预览；图下方展示监控名称及时间。
- 趋势图保留原统计和图例，图表高度设为 210px。
- 窄屏改为纵向布局；520px 以下图片逐张显示，保留可读性。两种主题共用语义色；图片遮罩固定白字/深色背景保证对比。

## 数据
- 新增只读接口 `GET /api/alerts/recent-snapshots`，按告警时间、ID 倒序返回最新三张不同的有效快照。
- 排除误报、已清理、缺失、根目录外图片。不会仅从最新十条告警中筛选，避免近期无图告警掩盖实际最新快照。
- 缩略图使用现有缩略图接口，灯箱加载原图。每 3 秒自动更新。
- 加载、无图、失败和图片失效分别提示，不伪造违规图片。

## 验证
- 后端测试覆盖最新三张排序、去重、误报/缺图/已清理/越界过滤和 API URL 编码；全量 59 项测试通过。
- 浏览器脚本 `dashboard-snapshots.cjs` 使用模拟图片及 API；覆盖 light/dark × 1440/1024/768/390/320，三张上限、布局对齐、图表高度、灯箱、单图/空态、失败恢复、无页面横向溢出。
- 测试不会新增告警或修改用户快照。截图仅包含标明 SYNTHETIC TEST IMAGE 的测试图片。
