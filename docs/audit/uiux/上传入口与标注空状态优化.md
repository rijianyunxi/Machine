# 上传入口与标注空状态优化

## 实施内容

- 检测页和模型页共用 `file-upload` 样式，使用现有语义色 token，不新增独立主题配色。
- 模型选择采用原生 button + 隐藏 file input，支持键盘操作；展示上传图标、格式和大小提示，长文件名省略并保留 title。
- 未选模型禁用上传；上传中锁定选文件入口；失败保留选择供重试，成功清空。
- 保留可信来源警告和现有 200MB 校验。
- 标注页用图标、标题、辅助说明构成统一空状态。左侧提示占满缩略图网格，中央画布提供唯一导入入口，右侧解释标注框出现的条件。
- 区分无数据集、数据集无图片、空分区、已选图片无标注、加载中及加载失败；空分区可切回全部，加载失败可重试。
- 无图片时禁用保存、YOLO 预标注和 AI 识别，避免提示用户在空画布上画框。

## 回归

- `model-picker.cjs`：light/dark × 1440/768/390/320，共 8 组；键盘选文件、长文件名、上传中禁用、失败重试、成功重置、无横向溢出。
- `annotate-empty.cjs`：light/dark × 1440/390/320 × 6 种状态，共 36 组；空提示文案、导入链接、操作禁用、网格宽度、分区恢复、加载重试、无横向溢出。
- 浏览器测试使用真实 SPA 和模拟 API；不上传真实模型，不写入真实标注。
- 结果 JSON 及截图位于同目录的 `model-picker/` 和 `annotate-empty/`。

运行示例（需要配置本机 Playwright 路径及浏览器可执行文件）：

```sh
PLAYWRIGHT_MODULE=/path/to/playwright \
UI_AUDIT_BROWSER=/path/to/chrome \
UI_AUDIT_BASE=http://127.0.0.1:8000 \
UI_AUDIT_OUT=docs/audit/uiux/annotate-empty \
node docs/audit/uiux/annotate-empty.cjs
```
